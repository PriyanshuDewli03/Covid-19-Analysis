# 🦠 COVID-19 Global Data Analysis

An end-to-end data analysis project using **Python** to explore global COVID-19 trends through data cleaning, exploratory data analysis (EDA), and visualization. The project analyzes confirmed cases, deaths, recoveries, and country-specific trends to generate meaningful insights into the pandemic's progression.

---

# 📌 Project Overview

This project performs an end-to-end analysis of global COVID-19 data using historical case records. The objective is to understand how the pandemic evolved across different countries by analyzing confirmed cases, deaths, recoveries, and active cases.

The project follows a complete data analysis workflow, including:

- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Time-Series Analysis
- Country-Specific Analysis
- Data Visualization

---

# 🎯 Business / Research Problem

Understanding the global spread of COVID-19 is essential for public health planning and decision-making.

This project transforms raw pandemic data into meaningful insights by analyzing historical trends, recovery rates, and active cases across countries, helping visualize the overall progression of the outbreak.

# 📈 Key Insights

- The dataset captures the global progression of COVID-19 from **January 2020 to July 2020**.
- Confirmed cases increased dramatically from **555** at the beginning of the dataset to over **16.4 million** by the end of July 2020.
- Country-level analysis highlights significant differences in infection and recovery trends.
- Time-series analysis provides insights into the progression of the pandemic across different regions.
